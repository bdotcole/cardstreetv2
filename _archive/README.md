# Archived diagnostic scripts

Everything in this folder is historical: one-off data-ingestion scripts,
debugging queries, deployment notes from earlier milestones. Kept under
version control for reference, but not part of the running app.

Nothing in here should be imported from `app/`, `components/`, or `lib/`.
If you find yourself reaching for one of these files for a production task,
that's a hint it should be promoted out (e.g. into `scripts/`) and cleaned up.

Safe to delete in bulk once you're confident the history view in git is
enough to recover anything you might need later.
